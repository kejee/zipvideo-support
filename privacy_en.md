## Core Privacy Commitment

### 🔒 All Video Processing is 100% Local

| Feature | Description |
|---------|-------------|
| 🏠 **Local Processing** | All video processing is completed on your device locally, no remote servers required |
| ☁️ **Zero Data Upload** | Your video files, compression parameters, and processing results are never uploaded to any server |
| 📡 **No Network Requests** | The app does not initiate any network requests during compression operation |
| 🛡️ **No Third-party Tracking** | No analytics, user tracking, or advertising SDKs are integrated |
| 🧹 **Auto Cleanup** | Temporary files generated during compression are automatically deleted after task completion |
| 📂 **Local Output Only** | Compressed videos are saved only to your device's photo album, fully under your control |

> ✅ **Core features work without network connection. Your video data never leaves your device.**

## Information Collection and Use

### 1. Information We Collect

#### Storage Permission (Photo Album/Media Files)
- **Purpose**: Read selected video files for compression processing and save compressed videos to the album
- **Usage Scenario**: Access album to read video files when selecting videos for compression; save compressed videos to album after completion
- **Impact of Refusal**: If permission is denied, you will not be able to use the video compression feature

#### Device Information
- **Content**: Device model, operating system version, app version number
- **Purpose**: Optimize app performance and troubleshoot technical issues
- **Method**: Automatically collected, stored only locally

### 2. Information We Do NOT Collect

We promise **NOT to collect** the following information:
- ❌ Identity information (name, ID number, phone number, etc.)
- ❌ Location information
- ❌ Contacts information
- ❌ SMS and call records
- ❌ Biometric information
- ❌ Any other personal information unrelated to core functions

## Permission Usage

### Android Permissions

| Permission | Purpose | Required |
|------------|---------|----------|
| READ_EXTERNAL_STORAGE | Read video files from external storage | Yes (Android 10 and below) |
| WRITE_EXTERNAL_STORAGE | Save compressed video files | Yes (Android 10 and below) |
| READ_MEDIA_VIDEO | Read video files | Yes (Android 13+) |

### iOS Permissions

| Permission | Purpose | Required |
|------------|---------|----------|
| NSPhotoLibraryUsageDescription | Access album to read and save videos | Yes |
| NSPhotoLibraryAddUsageDescription | Save compressed videos to album | Yes |
